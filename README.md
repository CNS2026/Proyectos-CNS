# Proyectos CNS

## Certificados de formación (`docs/`)

Sitio estático para GitHub Pages: verificación pública de certificados de formación de CNS
(sin cuentas, sin servidor) y panel de administración en `docs/admin/`.

- Público: `https://cns2026.github.io/Proyectos-CNS/`
- Administración: `https://cns2026.github.io/Proyectos-CNS/admin/` (token de GitHub + clave de cifrado)
- Los datos públicos están cifrados con el propio código del certificado; el libro con contacto y documento
  está cifrado con la clave de administración. Ver `docs/LEEME.md`.
