Acceso de administración

Solo el equipo de CNS puede emitir certificados. Necesitas el token de GitHub del repositorio y la clave de cifrado.

Mínimo 12 caracteres. Si la pierdes no hay forma de recuperar los datos privados (contacto y documento).

Emitir certificado de formación

Registra al estudiante que terminó su formación. Se genera un código único y un QR de verificación.

Solo se muestran los últimos 3 dígitos al verificar.
Dato privado: se guarda cifrado y no aparece en la verificación pública.

Certificados emitidos

Puedes revocar un certificado si se emitió por error; la verificación mostrará que ya no es válido.
